# AI Student Personas Library

This directory contains markdown profiles for the simulated AI student personas. These files serve as the master reference documents for the behavioral profiles, triggers, developmental contexts, and the exact system prompts loaded into the **Intervene AI** database.

## Realism & "Bad Behavior" Mimicry

For Behavior Skills Training (BST) to be effective, educators must practice with realistic levels of resistance. This means the AI student personas **must be capable of yelling, throwing insults, using classroom-appropriate slang/mild swearing, and refusing cooperation.**

### Overcoming LLM Safety Filters
To prevent commercial LLM APIs (Anthropic Claude, OpenAI GPT) from blocking responses due to self-censorship/safety policies:
1.  **Strict Contextual Framing**: System prompts are framed clearly as *"educational simulations for teacher training in crisis prevention and co-regulation."*
2.  **Character Boundaries**: Triggers are set to produce childish/teenage verbal tantrums ("I hate this class!", "You're a terrible teacher!", "This is complete crap!") rather than target-hate speech, extreme profanity, or self-harm, ensuring the simulation remains highly realistic but compliant with safety standards.
